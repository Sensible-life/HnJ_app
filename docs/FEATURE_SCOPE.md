## 1. PDF 원안의 기본 흐름

| 순서 | 기능 흐름 | 현재 제품 내 해석 |
| --- | --- | --- |
| 1 | 객실 선택 및 체크인 | 점검 대상 호텔/층/객실을 확인하고 점검 세션 시작 |
| 2 | 체크리스트 | ROOM PRO/BATH PRO 항목별 점검 |
| 3 | 사진/영상 등록 | 증빙 미디어 업로드, 워터마크, 마킹 |
| 4 | 상태등급 판정 | 정상/주의/긴급/해당 없음 |
| 5 | 실시간 보고서 | 웹/PDF 리포트, 알림, 호텔 확인 |
| 6 | 관리이력 | 객실별 과거 점검/수리/사진 비교 |
| 7 | 통계 | 일일/월간/호텔/담당자/청소팀 지표 |

## 4. 추가 구현 백로그

### 우선순위 A - 점검/리포트 품질에 바로 영향

- `해당 없음` 상태 추가
- 서비스 구분 추가: 최초 리뉴얼 / 정기점검 / 긴급출동 / 재점검
- 항목별 문제 내용, 조치 내용, 담당자 의견 입력
- 호텔 승인 필요 여부 입력
- 호텔 담당자 의견/답변 입력
- 실제 호텔 선택/담당자 선택 흐름 정리

### 우선순위 B - 운영/관리 고도화

- 객실 유형 기록
- 청소 담당팀 및 청소 완료시간 기록
- 분실물 발견 여부 및 보관 장소 기록
- 담당자별 점검 실적
- 호텔별 문제 발생 순위
- 객실별 문제 발생 횟수
- 반복 문제 객실/재발 횟수
- 전월 대비 개선율
- 화장실 상태 변화 그래프
- 청소팀별 인스펙션 점수
- 날짜별 사진 비교
- 긴급출동/재점검 일정 타입
- 호텔 담당자와 일정 공유

### 우선순위 C - 비용/인프라 영향 큰 후순위

- 짧은 동영상 등록
- SMS 문자 알림
- PDF 공유 UX
- 요금 관리

| `Schedule` | `scheduleType = REGULAR/EMERGENCY/REINSPECTION`, share status |
| 신규 모델 후보 | `CleaningTeam`, 통계 집계용 read model 또는 view |

## 6. IA 메모

PDF 원안의 하단 메뉴는 `홈 / 화장실 케어 / 객실 인스펙션 / 리포트 / 관리이력`이다. 현재 앱은 정보를 줄이기 위해 `홈 / 현장 점검 / 이슈 / 프로필` 구조를 쓴다.

현재 IA를 유지하더라도 기능 스코프는 아래처럼 흡수한다.

| PDF 메뉴 | 현재 IA 내 위치 |
| --- | --- |
| 홈 | 홈 |
| 화장실 케어 | 현장 점검 내부 BATH PRO |
| 객실 인스펙션 | 현장 점검 내부 ROOM PRO |
| 리포트 | 이슈/승인 웹뷰/관리자 웹 |
| 관리이력 | 관리자 웹 객실 타임라인, 추후 모바일 진입점 검토 |
| 일정/직원/권한 | 관리자 웹 또는 관리 메뉴 |
